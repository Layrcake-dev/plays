# Security policy

## Reporting a vulnerability

Email founders@layrcake.dev with "Security" in the subject line. Include the play or file, what you saw and how to reproduce it. We reply within two working days and keep you updated until it is fixed.

Please do not open a public GitHub issue for a security problem.

## Scope

This repository holds instructions only (`SKILL.md` files, manifests and an MCP server reference). It runs no code on your machine. The plays talk to one service, the Layrcake MCP server at https://mcp.layrcake.dev/mcp, which is covered by this policy too.
